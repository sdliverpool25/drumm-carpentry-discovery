# Drumm Carpentry discovery

An editable, public GitHub Pages workspace capturing Digital Drumm’s discovery session with Mary (bookkeeper) at Drumm Carpentry, November 2026.

**Live page:** to be published at `https://sdliverpool25.github.io/drumm-carpentry-discovery/` once this repository is on GitHub Pages (main branch, root).

## What it contains

- Key notes on deposits, staged payments, the Schedule Sheet, and fixed payments
- A whiteboard for Lami and staff to add sticky notes
- A stakeholder map (hierarchy or department view)
- Tech stack: Sage, Gmail, Google Sheets (Schedule Sheet), AIB, WhatsApp, and the custom ERP in progress
- Process maps for daily bank reconciliation, supplier invoice processing, and quote → deposit → schedule → invoice
- Use cases #1–#9, with the creditors report pinned at the top
- The September 2026 monthly reports checklist

Everything on the page is editable. Changes autosave in the current browser only (`localStorage`). They are not written back to GitHub. Use **Export JSON** or **Download HTML** to keep a copy, and **Import JSON** to load it on another device.

## Privacy

This site is public. Customer names, addresses, phone numbers, emails, IBAN/BIC/sort codes, account numbers, VAT/CRO numbers and exact loan amounts are not included. Quote figures are generic examples only.
